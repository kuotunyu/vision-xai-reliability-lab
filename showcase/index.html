主要實驗結果與解讀限制

Localization 與 baseline

—

Center prior 的 pointing game 分數較高

固定 center blob 的 pointing game 分數高於所有受測 attribution method，顯示 localization 指標會受到 dataset composition bias 影響；localization 不是 causal faithfulness。

Model-randomization sanity check

—

IG 未通過 randomization sanity check

Integrated Gradients 在 head randomization 後仍保留顯著 similarity， 未符合預先定義的低 similarity expectation。

Spurious-patch experiment

—

未觀察到預期的 patch shortcut

Frozen-backbone、head-only model 未學到預期的 patch shortcut。 此負結果僅適用於本實驗設定，不延伸為 general robustness。

各項 metric 回答不同的評估問題

這份 benchmark 分開呈現 localization、faithfulness 與 sanity check，避免將良好的 localization score 誤解為 model sensitivity。
