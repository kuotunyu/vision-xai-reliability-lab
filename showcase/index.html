主要結果與解讀限制

定位能力與基準

—

Center prior 的 pointing game 分數較高

固定中心 blob 的分數高於所有受測歸因方法，顯示定位結果會受資料集組成偏差影響； 定位能力不代表因果忠實度（causal faithfulness）。

模型隨機化檢查

—

IG 未通過模型隨機化檢查

Integrated Gradients 在分類 head 隨機化後仍高度相似， 未達預先定義的低相似度門檻。

Spurious patch 負結果

—

未觀察到預期的 shortcut

Frozen backbone 與 head-only model 未學到預期的 patch shortcut。 此負結果僅適用於本實驗設定，不延伸為整體穩健性（general robustness）。

CUDA 續訓 canary：狀態等價性檢查

以小型、可重現的 CUDA 工作負載建立不中斷參考組（uninterrupted reference），再於 epoch 邊界 控制中斷，並由新的 process 恢復訓練。這只驗證續訓機制，不等同完整 L4 實驗。
