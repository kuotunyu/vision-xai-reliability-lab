# Source snapshot boundary

This repository was created as a new public-candidate snapshot from source
commit `e4481c2325557df888874e083b6365e50e3eba1f`.

Imported material is limited to reviewed source code, synthetic-fixture tests,
configuration, packaging and container files, public documentation, the
full-scale aggregate result, six generated figures, and three safe
data-preparation summaries.

The snapshot deliberately excludes the source Git history, virtual
environments, caches, downloaded Oxford-IIIT Pet data, manifests containing
per-sample file records, checkpoints or weights, per-sample attributions,
private progress/handoff notes, machine-bound notebook configuration, and
runtime output. The source repository is an immutable archive and was clean at
the recorded commit before and after the audit.

This is a provenance statement, not a claim that the aggregate result can be
re-derived without downloading the dataset and pretrained backbone weights.
